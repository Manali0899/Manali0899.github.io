Software Engineer | Backend Developer | Full-Stack Developer

I'm a software engineer at MTA New York City Transit, where I build Python and Django services for the Production Planning team. My main project is a labor scheduling system that plans the next year's labor schedule, handles changes as they come in, and produces the reports planners rely on.

Before MTA, I spent a little over a year at Accelya in Mumbai working in Java and Spring on Revera, an airline product, where I integrated REST APIs and file feeds for more than seven airline clients and fixed high-priority production issues through go-live. I hold a Master's in Computer Science from Pace University. I like backend work where the data has to be right and the system has to keep running.
